# CRUD de contactos

Aplicación web básica para practicar las operaciones CRUD:

- Crear contactos.
- Consultar y buscar contactos.
- Editar contactos.
- Eliminar contactos con confirmación.

Los datos se almacenan localmente en el navegador mediante `localStorage`, por lo que no requiere servidor ni dependencias.

## Uso

Abre `index.html` en tu navegador.
